The HOW TO TEST section is the important part - a reviewer cannot exercise this
extension without a Gemini API key of their own.

================================================================

WHAT IT DOES
When the user opens a YouTube video, the content script reads the video's
details (title, channel, description, tags, YouTube category, length) from the
page and sends them to Google's Gemini API. The model returns a category (from
a fixed 20-item list) and a 0-100 score. The extension then blocks or allows
the video according to rules the user configured. Channel lists and blocked
title words are matched locally, without any request.

Optional, all off by default: feed filtering (judges video tiles before they
are clicked), a pause of 5-60 seconds before every video, and Strict mode
(a hard score limit with no "Watch anyway", a daily number of "Watch anyway",
and a delay before settings can be loosened - kept in local storage under
"strictPending" until its time; nothing is sent anywhere). Saving settings
makes each YouTube tab's content script reload its own tab
(storage.onChanged -> location.reload()); no tabs permission is used.

HOW TO TEST WITHOUT A KEY
1. Install; the settings page opens automatically.
2. Under "Channels and title words", add a word from a YouTube video's title
   to "Always block titles containing" (e.g. "vector*"), and save.
3. Open a video with that word in its title, e.g.
   https://www.youtube.com/watch?v=fNk_zzaMoSs - the player is paused and a
   blocking screen shows "Take me back" and "Watch anyway".
   No request is made: local rules never reach Google.
4. Optional: under "Pause before every video", tick "Hold every video behind
   a breathing exercise first", save, and open any video - a
   breathing exercise holds it for the chosen seconds, then it plays.
5. Optional: tick Strict mode, set "Allow Watch anyway only 1 time a day",
   save, and open the blocked video twice - the second time the button is gone.

HOW TO TEST WITH A KEY
1. A free Google AI Studio API key: https://aistudio.google.com/apikey
   Tick the 18+ confirmation, paste the key and press "Test connection".
2. In "Category rules", set for example Gaming to Block, and save.
3. Open any gaming video on YouTube. The player is paused and a blocking screen
   appears. If a redirect address is configured instead, the tab navigates there.

NETWORK ACTIVITY
Exactly one endpoint is contacted: https://generativelanguage.googleapis.com
Authentication is the user's own API key, sent in the x-goog-api-key header
(never in a URL). There is no developer-operated server, no analytics and no
telemetry of any kind.

DATA HANDLING
Transmitted: video title, channel name, description (up to the first 1,500 characters),
tags, YouTube category and length, only for videos the user opens; in the
Smart (default) and Thorough modes, also the video's public YouTube link,
which the user can switch off by choosing Standard.
Stored locally (browser storage only, never transmitted): the API key, the
user's settings, and a cache of verdicts (video ID, category, score, reason,
and for watched videos a short summary) capped at
5000 entries with a 30-day default TTL.
Never accessed: browsing history, cookies, account data, watch history. The
extension never downloads or uploads video or audio.

THE API KEY IS NOT COLLECTED DATA
The user supplies their own Google AI Studio key. It is stored in local
extension storage and sent only to Google, as the authentication header for the
user's own request. It is never transmitted to the developer; there is no
developer server that could receive it.

PERMISSIONS
- *://*.youtube.com/*  read the details of an opened video; block or redirect it
- https://generativelanguage.googleapis.com/*  send those details (and optionally
  the video's public link) to Gemini
- storage  persist the key, settings, cache and the Strict-mode counter locally

SOURCE CODE
No build step, no minification, no bundler, no remote code. The submitted
package is the complete, readable source. All scripts are plain ES2022. There is
no eval, no new Function, and no remotely-hosted script.

PROMPT INJECTION HANDLING
Video titles, descriptions and tags - and, when Gemini watches, anything said
or shown in the video - are attacker-controlled. They are wrapped in
<video_list> / <video_metadata> delimiters and the system prompt instructs the
model to treat them strictly as data, and to categorise anything containing
embedded instructions as "other" with a score of 0.
